## 📖 Overview

Most digital wellness and screen-time blocker apps fail for a predictable reason: **they treat human psychology like a binary firewall**. 

When an app simply blocks your screen or forces a rigid 5-second countdown, two psychological reactions occur:
1. **Automated Motor Bypass:** Within days, your brain maps the bypass button into motor reflex. Your thumb taps through the breath screen without your conscious mind ever waking up.
2. **Adversarial Reactance:** Recurring 5-minute nag popups create an antagonistic relationship with your device. You begin fighting the blocker rather than evaluating your relationship with social media.
3. **Intimacy Friction:** When you open Instagram or WhatsApp solely to reply to a partner, rigid blocking creates frustration and trains you to aggressively disable the intervention.

**Mora** was conceived and engineered after an intensive 1-week field trial on a **Realme GT 6** running **Android 16 / ColorOS 17**. Mora replaces blunt-force blocking with **Adaptive Cognitive Friction**, **Protected Intimacy**, and an **Intentional Execution Ledger**.

## 🔬 The UX Case Study: The Realme GT 6 Reality Check

```
+---------------------------------------------------------------------------------+
|                                 THE REALITY GAP                                 |
+---------------------------------------------------------------------------------+
| TRADITIONAL BLOCKERS:                                                           |
| [Open App] ---> [Rigid 2-Breath Wall] ---> [Bypassed by Muscle Memory in <2s]   |
|                                                                                 |
| MORA ADAPTIVE FRICTION:                                                         |
| [Open App] ---> Under Budget? ---> [1-Tap Texting Pass (5m) OR 2 Breaths (5m)]  |
|            ---> Over Budget?  ---> [Prefrontal Typing Friction: Intent Decoupling]|
|            ---> At 5 Minutes  ---> [Conscious Check-Out Sheet (Non-Adversarial)]|
+---------------------------------------------------------------------------------+
```

### Insight 01: The Habituation Trap (Motor Reflex Bypass)
During live testing, static 2-breath pauses became an automated motor reflex within 7 days. Because the physical interaction pattern was always identical, the subconscious motor cortex took over. Mora solves this by introducing **Tiered Friction**: when under daily budget, friction is gentle; once over daily budget, the interaction requires **typing your raw intent**, shifting cognitive load from the motor cortex (System 1) to the prefrontal cortex (System 2).

### Insight 02: Adversarial Reactance (The 5-Minute Nag Revolt)
Traditional interventions interrupt scrolling every 5 minutes with harsh warning banners. Field testing proved this triggers psychological reactance - the user feels policed and responds with annoyance, reflexively dismissing alerts. Mora replaces nagging with a **Conscious Check-Out Sheet** at the 5-minute mark that celebrates mindful wins and offers respectful closure (`"Did you finish what you came for?"`).

### Insight 03: Protected Partner Intimacy
A major source of friction in existing apps is interrupting legitimate, affectionate communication. When opening an app to answer a message from a partner, being greeted by a cold restriction dialog trains the user to seek bypasses. Mora provides an instant **1-Tap Pass for Texting** (5 minutes, zero breath delay) and surfaces an emotional grounding anchor: **Sarah's Partner Note**.

## ✨ Key Features

### 1. Adaptive Launch Gate (Protected Intimacy)
- **Live Daily Budget Tracker:** Displays real-time daily usage (e.g. `18m / 30m Used`) powered by Android's native `UsageStatsManager`.
- **Partner Anchor Card:** Displays a customizable, grounded quote from your partner (e.g. *"Remember our weekend plan, baby! Don't get lost in reels."*).
- **Dual Intention Decision Matrix:**
  - `[1-TAP PASS]` **Just Texting / Replying (5m):** Zero breaths, zero delay. Respects real-world intimacy without triggering habitual scrolling.
  - `[2 BREATHS]` **Mindful Browsing (5m):** Conscious pause with animated breathing rings for intentional content consumption.

### 2. Prefrontal Cognitive Stop (Over-Budget Friction)
- Activates automatically when daily usage exceeds the allotted limit (e.g. `32m / 30m`).
- **Interactive Typed Intent:** Requires the user to type their genuine state of mind (e.g. *"I am bored and avoiding finishing tasks"*) to break automated thumb reflexes.
- **Impulse Decoupling CTA:** High-contrast `Close Instagram & Return to Focus` button paired with a muted tertiary extension.

### 3. Conscious Check-Out Sheet (Non-Adversarial Closure)
- Appears calmly at the end of a 5-minute micro-session.
- **Mindful Exit Streak:** Rewards conscious closures with positive reinforcement (e.g. `Streak: 6 Mindful Exits Today`).
- **Choice-Driven Closure:**
  - `[Yes, I'm Done - Close App]` — Closes foreground app and logs a Mindful Win.
  - `[Need 2 More Mins for a Chat]` — Extends session by 120 seconds for conversation completion.

### 4. Mindful Hub & Life Reclaimed Dashboard
- **Life Reclaimed Tracker:** Displays total daily time saved from mindless algorithmic loops (e.g. `1h 42m Life Reclaimed Today`).
- **Monitored Apps Budget Manager:** Interactive budget sliders for high-friction apps (Instagram, YouTube, X / Twitter, TikTok).
- **Partner Anchor Quote Manager:** Edit and configure anchor notes across designated target apps.

### 5. High-Conversion Tasks Ledger
- **Priority Stripes:** Visual hierarchy distinguishing active, upcoming, and overdue commitments.
- **1-Tap Overdue Recovery Chips:** Instantly reschedule overdue tasks (`+1h`, `Tonight`, `Tomorrow`) without guilt-inducing friction.
- **Focus Blocks with Notion Sync:** Real-time bi-directional synchronization with Notion task databases.

## 🎨 ColorOS 17 Liquid Glass Design System

Mora is built upon an editorial, concentric glassmorphic design system tailored for modern flagship Android hardware (specifically verified on the Realme GT 6):

| Token | Value | Semantic Purpose |
|---|---|---|
| **Obsidian Void** | `#080C0A` | Deepest background canvas for OLED contrast |
| **Glass Fill** | `#121D17` (88% Opacity) | Concentric frosted modal and card containers |
| **Specular Border** | `1px Linear Gradient` (18% → 4% White) | Simulates real physical glass rim refraction |
| **Emerald Accent** | `#4ADE80` | Primary conscious CTA and mindful streak indicators |
| **Cognitive Amber** | `#F59E0B` | Over-budget warning and prefrontal friction caret |
| **Corner Smoothing** | `0.6` | Continuous curvature squircle matching ColorOS 17 |
| **Background Blur** | `40px Gaussian` | Native `WindowManager.LayoutParams.FLAG_BLUR_BEHIND` |

### Triple-Theme Engine
1. **Obsidian Forest (Default):** Deep atmospheric obsidian and emerald green for nighttime calm.
2. **Pure AMOLED Black (`#000000`):** Complete pixel shutdown for Realme GT 6 8T LTPO display battery optimization.
3. **Editorial Warm Linen (`#F5F3EC`):** Warm book-paper contrast for daytime outdoor reading.

## 🏗 Technical Architecture

```
app/src/main/java/com/dueordie/mora/
├── core/
│   ├── designsystem/          # Liquid Glass theme, squircle tokens, typography scale
│   ├── database/              # Room DB entities, DAOs, and migrations
│   └── network/               # Notion API client and bi-directional sync engine
├── data/
│   ├── repository/            # TaskRepository, UsageBudgetRepository, PreferencesRepository
│   └── preferences/           # EncryptedSharedPreferences for anchor notes and limits
├── domain/
│   ├── model/                 # Task, UsageBudget, MindfulSession, LaunchGateState
│   └── usecase/               # CalculateLifeReclaimedUseCase, EvaluateLaunchGateFrictionUseCase
├── overlay/
│   ├── OngoingNotificationService.kt # Foreground service managing WindowManager overlay
│   └── LaunchGateOverlayView.kt      # ComposeView rendering Liquid Glass over target apps
└── presentation/
    ├── hub/                   # Mindful Hub & Life Reclaimed screen
    ├── ledger/                # High-conversion Tasks Ledger screen
    ├── settings/              # Daily Budgets & Partner Anchor settings
    └── navigation/            # Liquid Glass Bottom Navigation Dock
```

### Key Engineering Implementations
- **Native Glassmorphism:** Implemented using Android's `WindowManager.LayoutParams.FLAG_BLUR_BEHIND` with `setBlurBehindRadius(40)` on Android 12+ (API 31+).
- **Sub-Second App Interception:** Efficient background monitoring combining `AccessibilityService` event triggers with `UsageStatsManager` session aggregation.
- **Offline-First Ledger:** Room Database backing with Kotlin `Flow` reactive streams and offline mutation queues for Notion sync.

## 🚀 Getting Started

### Prerequisites
- **Android Studio:** Ladybug (2024.2+) or Meerkat
- **JDK:** Version 17+
- **Android SDK:** Compile SDK 35, Min SDK 26 (Android 8.0+), Target SDK 35 (Android 15/16)
- **Target Device:** Any Android device running Android 11+ (Optimized for Android 15/16 and ColorOS 17)

### Installation & Build

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-username/mora.git
   cd mora
   ```

2. **Open in Android Studio:**
   Open the directory in Android Studio and allow Gradle to complete synchronization.

3. **Build the Debug APK via CLI:**
   ```bash
   # On macOS / Linux
   ./gradlew assembleDebug

   # On Windows PowerShell
   .\gradlew.bat assembleDebug
   ```

4. **Install to connected device (e.g. Realme GT 6 via ADB):**
   ```bash
   adb install -r app/build/outputs/apk/debug/app-debug.apk
   ```

### Required Permissions
Upon first launch, Mora will guide you to grant:
1. **Usage Access:** To calculate daily per-app budgets via `UsageStatsManager`.
2. **Display Over Other Apps (Overlay):** To render the Liquid Glass pause sheet over target apps.
3. **Accessibility Service (Optional):** For instant launch detection on ColorOS and modern Android skins.
